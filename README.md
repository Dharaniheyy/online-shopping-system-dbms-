##ProjectDescription
This project designs and implements a **relational database for an Online Shopping System**.  
It manages six core entities — **Customer, Category, Product, Order, OrderItem, and Payment** — through a well-normalized schema (up to 3NF).  
An ER diagram was created, mapped to a relational schema with Primary Keys and Foreign Keys, and implemented in **PostgreSQL** with integrity constraints (PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK).  
Sample data was inserted, and SQL operations including **DDL, DML, DQL, Joins, Aggregates, Views, Subqueries, DCL and TCL** were successfully executed.  
The system eliminates data redundancy, enforces referential integrity, and supports essential e-commerce operations such as product catalogue management, order processing, and payment tracking.
